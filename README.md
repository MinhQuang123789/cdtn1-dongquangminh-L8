# Phân tích hiệu suất bảo hành và tỷ lệ lỗi linh kiện - Mekong Mobile

- **Sinh viên:** Đồng Quang Minh
- **Học phần:** Chuyên đề Tốt nghiệp 1, HK1 2026-2027
- **Track:** DA (Data Analytics)
- **Luồng nghiệp vụ:** L2 - Phân tích dữ liệu tiếp nhận và xử lý bảo hành

## 1. Mục tiêu
Hệ thống phân tích dữ liệu bảo hành của Mekong Mobile giúp xác định tỷ lệ hư hỏng linh kiện theo từng dòng máy, đo lường thời gian xử lý của kỹ thuật viên và cung cấp dữ liệu hỗ trợ quản lý kho linh kiện.

## 2. Yêu cầu môi trường
- Python 3.11+
- SQLite / PostgreSQL 16
- Thư viện: pandas, sqlalchemy, jupyter, python-dotenv, matplotlib, seaborn
- Biến môi trường: xem file `.env.example`
